# Borderly stabilization report

## Update v1.1.1 / Data v17

- Встроенная резервная база обновлена до visa data v17.
- Тайм-аут соединения увеличен с 7 до 15 секунд, чтения — с 10 до 30 секунд.
- Для временных сетевых ошибок и HTTP 408/425/429/5xx выполняются до трёх
  попыток; ошибки контракта, SHA-256 и структуры данных не маскируются повторами.
- Неудачная загрузка никогда не заменяет последнюю проверенную базу и теперь
  записывает точную причину в Logcat с тегом `BorderlyVisaUpdate`.

- Удалена неоднозначная вложенная структура Gradle; остался один проект и один
  модуль `:app`.
- База больше не разбирает 49 тысяч JSON-правил заново при каждом расчёте
  рейтинга: правила предварительно преобразуются в типизированные карты.
- Добавлена строгая таксономия из 10 категорий; `special permit` и
  `mixed requirements` больше не превращаются в `NO_DATA`.
- eTA/ESTA отделены от arrival card и других формальностей.
- Удалён дублирующий фильтр «Только без визы»; «Без визы» теперь не включает
  свободу передвижения.
- Смена основного паспорта сбрасывает визовый фильтр.
- Поиск поддерживает отображаемое название, ISO alpha-2, alpha-3 и numeric.
- Исправлено сохранение основного состояния при повороте экрана.
- Нажатие на строку рейтинга сначала открывает сведения и отдельную кнопку
  «Показать доступные страны».
- Возвращена визуальная индикация нажатия; малые кнопки и подписи увеличены.
- Добавлена безопасная загрузка remote data с SHA-256, immutable releases,
  атомарной записью и предыдущей рабочей копией.
- В visa data v17 сохранено происхождение всех правил. 38 418 обычных
  core-связок строго совпадают с закреплённым снимком Passport Index, а 984
  core-правила защищены отдельным официальным источником.
- Некоммерческий сравнительный слой удалён из активной базы и workflow. Все 25
  ранее ожидавших проверки территорий получили официальные матрицы — 4 975
  связок. Одна явно неразрешённая связка остаётся `NO_DATA` и не влияет на
  рейтинг.
- Карточка страны теперь
  различает официальный источник конкретного правила, общий набор данных и
  производное территориальное правило и не выдаёт GitHub за подтверждение
  государственного органа.
- Для общего набора кнопка источника открывает конкретный неизменяемый снимок,
  а не меняющуюся главную страницу проекта.
- Категория `eta` в интерфейсе везде подписана `eTA/ESTA`; eVisa, виза по
  прибытии и arrival card остаются отдельными категориями/формальностями.
- Добавлены unit tests, статическая JSON-проверка и Android CI.

Полная Android-сборка требует установленного Android SDK 37 и должна пройти
workflow/Android Studio перед установкой на устройство. В текущем изолированном
окружении Gradle distribution недоступен по сети; все независимые проверки JSON
и полный набор data validators успешно пройдены.
