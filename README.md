# Borderly Android

Стабилизированная версия проекта без добавления новых продуктовых функций.

## Как открыть и собрать

1. В Android Studio откройте именно корневую папку `Borderly`, где находятся
   `settings.gradle.kts`, `gradlew` и папка `app`.
2. Выберите JDK 17 для Gradle.
3. Установите Android SDK Platform 37; `targetSdk` остаётся 36.
4. Нажмите **Sync Project with Gradle Files**.
5. Запустите **Build > Assemble Project** или в терминале:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

В проекте оставлен один Gradle-модуль `:app`. Кэши, старые build-артефакты и
вложенная копия Android-проекта в архив не включены.

## Данные

В приложение встроена проверенная база visa data v17:

- 199 паспортов;
- 248 направлений;
- 49 153 визовых правила;
- 10 взаимоисключающих категорий, включая безопасное «Нет подтверждённых данных»;
- происхождение источника для всех 49 153 правил;
- arrival card и другие невизовые формальности хранятся отдельно.
- 38 418 обычных core-правил точно совпадают с закреплённым снимком Passport
  Index, а 984 core-исключения имеют отдельное официальное подтверждение.
- 25 отдельных территорий имеют проверенные официальные матрицы: 4 975 правил;
- ожидающих территориального аудита направлений нет.

При запуске приложение не чаще раза в 24 часа проверяет GitHub Pages. При
временной сетевой ошибке выполняются до трёх попыток с паузами; загрузка базы
не блокирует интерфейс. Новый
релиз принимается только после проверки schema/taxonomy/provenance version, точного
неизменяемого имени файла, SHA-256, размера и полной матрицы. Сначала файл
полностью скачивается и валидируется, затем заменяет рабочий кэш атомарно.
Повреждённое обновление, старая версия или несовместимая таксономия не ломают
запуск: используется последняя рабочая либо встроенная база.

## Проверки

Локальная проверка встроенных JSON без Android SDK:

```bash
node scripts/verify_bundled_data.mjs
```

GitHub workflow `.github/workflows/android-ci.yml` выполняет JSON-проверку,
unit tests, Android Lint и сборку debug APK. APK публикуется как artifact только
после успешного прохождения всех этапов.

## Важно

Рейтинг неизменно считает только `Без визы + Свобода передвижения`. eTA/ESTA,
электронная виза и виза по прибытии в балл не входят. Географические фильтры
следуют UN M49; Kosovo явно отнесено к Европе.

Удалённый репозиторий `borderly-data` должен быть обновлён согласованным
архивом Data v17. Более старая сборка с taxonomy v1 безопасно отклонит v17 и
продолжит использовать свою последнюю совместимую базу; текущая сборка принимает
taxonomy v2 после полной проверки матрицы и SHA-256.
