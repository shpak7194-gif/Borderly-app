Borderly v60 — регионы, ISO-поиск и фильтры

Основа: фактический рабочий проект v59 пользователя.
Удалённая visa database v6 не изменялась.

Исправлено:
- Гренландия и Сен-Пьер и Микелон больше не попадают в Европу; обе территории относятся к Америке.
- Удалён опасный fallback неизвестного региона -> Европа. Все 248 реальных направлений распределены явно.
- Списки стран и региональные счётчики строятся только по 248 реальным направлениям Borderly; три служебные геометрии карты не входят в каталог/счётчики.
- Поиск паспорта, страны и поиск в рейтинге понимают название, ISO alpha-2, ISO alpha-3 и numeric code. Примеры: RU / RUS / 643, US / USA / 840, DE / DEU / 276.
- Для Kosovo поддерживаются используемые Borderly aliases XK / XKX / 983.
- При смене основного паспорта фильтр карты всегда сбрасывается на «Все».
- «Свобода» заменено на «Свобода передвижения».
- «По прибытии» заменено на «Виза по прибытии».

Не изменялось:
- visa_requirements.json и borderly-data v6;
- GitHub updater;
- entry guides;
- рейтинг и формула рейтинга;
- карта/zoom/pan/hit-test;
- нижняя навигация;
- duplicate «Без визы / Только без визы» пока не трогался, потому что в старом сообщении пользователя фраза «оставь ...» была обрезана.
- rememberSaveable/поворот экрана и touch feedback оставлены на следующие этапы.
