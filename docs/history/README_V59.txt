Borderly v59 — 199 паспортов × 248 направлений

Основа: полный проект Borderly v58.

Что изменено:
- паспортные документы и направления разделены в модели данных;
- в выборе остаются 199 паспортов;
- карта и карточки покрывают 248 стран и территорий;
- добавлены 33 кликабельных маркера отсутствовавших территорий;
- каждая строка визовой базы содержит ровно 247 иностранных направлений;
- рейтинг по-прежнему считает только «Без визы» и «Свобода передвижения»;
- eTA/ESTA, eVisa и виза по прибытии не дают рейтинговый балл;
- старая удалённая база без destinationCount=248 больше не заменяет новую;
- в методике рейтинга отображается фактическое количество направлений.

Проверка Великобритании в этой сборке:
- 151 направление без визы;
- рейтинг пересчитывается по единой формуле для всех 199 паспортов.

Как открыть полный архив:
1. Распакуйте папку Borderly_v59.
2. Откройте её в Android Studio.
3. Дождитесь Gradle Sync.
4. Нажмите Run.

Для уже установленного приложения сначала опубликуйте data-репозиторий v6
с version.json версии 5. Затем установите v59 или нажмите в приложении
«Проверить обновления».
